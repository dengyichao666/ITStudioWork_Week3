# 第 1 课作业：图书角数据库

## 1. 环境与运行顺序
- 数据库版本：MySQL  (8.4)
- 运行顺序：
  1. 在 MySQL 中执行 `sql/schema.sql` 建库建表。
  2. 执行 `sql/seed.sql` 插入测试数据。
  3. 执行 `sql/queries.sql` 运行查询和修改操作。

## 2. 主键与外键解释
- **主键 (Primary Key)**：在 `authors` 表中，`id` 是主键。它就像人的身份证号，每一行都有一个独一无二的编号，不能重复，也不能为空。
- **外键 (Foreign Key)**：在 `books` 表中，`author_id` 是外键，它指向 `authors` 表的 `id`。这表示“这本书属于哪位作者”，保证了数据的一致性（不能插入一个不存在的作者的書）。

## 3. 遇到的问题及解决
- **问题**：在配置环境时，MySQL Workbench 显示 Offline（离线）。
- **解决**：通过检查发现是 Windows 服务中的 MySQL 服务没有启动。按 `Win+R` 输入 `services.msc`，找到 MySQL 服务手动启动后，重新连接成功。
